Offline Microtools

单文件、完全离线的浏览器小工具 —— 打开即用，不装软件、不注册、不联网。所有数据只存在你自己的浏览器里（localStorage / 导出文件）。

零网络请求零依赖MIT数据不出本机

工具

NeverLose — 不丢的收集箱

输入即落盘的笔记 / 灵感 / 待办收集工具。刷新、崩溃、断电都不会丢内容。

  • 输入即落盘 + 版本留存（可回滚）
  • 全文搜索、标签与分类过滤、按名称/时间排序
  • 导出 JSON / CSV / Markdown
  • 存储占用显示与告警

Recall — 离线记忆卡（SM-2）

纯离线的间隔重复记忆卡：牌组、标签、今日到期、复习打分。

  • 标准 SM-2 排程算法
  • JSON / CSV 导入导出，方便备份与迁移
  • 写盘失败自动回滚，不会写坏数据

Offline UI Icons — 32 枚离线 UI 图标

24×24 网格的线性图标集，纯 SVG（currentColor），零依赖、零网络；另附单文件 JS 版本。

下载

成品都在 GitHub Releases 里，公开仓库、无需登录即可下载：

NeverLose + Recall（zip） Offline UI Icons（zip）

每个发布包都附带 SHA256SUMS，下载后可自行校验；每个 zip 内的单文件工具双击即可在浏览器里离线运行。

自证没坏

不放心二进制？每个 zip 附哈希清单，仓库里还有一条命令跑完全部校验（哈希、单元测试、结构检查、离线/身份扫描）。也可以直接打开仓库里的 QUICKSTART.html：它在本地用浏览器 crypto 重算内嵌文件的 SHA-256 并逐项比对。
